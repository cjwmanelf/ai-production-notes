# AI 데모를, 계속 쓰는 서비스로.

「AI 서비스 인 프로덕션_Agt1」 모듈을 바탕으로 작성한 한국어 학습 블로그입니다. AI 기능을 처음 운영하는 학습자를 위해 설계 → 배포 → 관측 → 평가 → 개선의 흐름으로 설명합니다.

**[블로그 읽기](https://cjwmanelf.github.io/ai-production-notes/)**

## 담은 내용

- 서비스 사용 맥락과 PRD, 처리 방식 및 오류 대응
- Docker, CI/CD, staging과 이미지 승격
- 무상태 구조, 블루그린·카나리 배포와 롤백
- Langfuse 트레이스와 실패·정상 사례를 함께 사용하는 평가
- 원가·크레딧·멱등성, 모바일 앱의 개발과 출시
- 가상의 학습 회고 도우미에 적용한 운영 계획

트래픽 비율, 가상 트레이스, 요청량별 비용을 조작하며 개념을 확인할 수 있습니다. 예시와 계산값은 학습용 가정이며, 실제 운영 결과나 제공사 가격을 의미하지 않습니다.

## 실행

외부 라이브러리와 빌드 과정이 없는 HTML/CSS/JavaScript 페이지입니다.

```sh
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다. 정적·동작 검증은 `node tests/check.mjs`로 실행합니다.

## 구성

여섯 장의 학습 기록과 세 가지 인터랙티브 예시로 구성했습니다. 예시의 수치는 개념을 설명하기 위한 가정입니다.

GitHub Pages는 `main` 브랜치의 루트에서 배포합니다.
